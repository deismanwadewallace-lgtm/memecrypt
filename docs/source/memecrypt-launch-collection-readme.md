## 2. Zombie Idea Field Guide

**Price:** CAD $32  
**SKU:** MCR-DECK-FG001  
**Category:** Learning tools  
**Format:** 36-card field deck in a matte tuck box

**Card copy:** Identify before you amplify.

**Product description:**

A pocket identification system for ideas that refuse to stay buried. Each field card records a specimen's habitat, transmission vector, preferred host, mutations, and undead rating. Use it to slow the reflex to share, compare recurring patterns, and ask what disappeared when the idea was compressed.

Planned deck structure:

- 24 specimen and pattern cards
- 5 observation cards: Habitat, Vector, Host, Mutation, and Undead Rating
- 6 critical-response prompts
- 1 quick-reference rating key

This is an educational observation tool, not a diagnostic instrument.
